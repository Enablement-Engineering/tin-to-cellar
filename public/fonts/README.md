# Local fonts

These unmodified Latin WOFF2 files implement the type families in the supplied Tin to Cellar Design System. The app serves them from its own origin. Font loading does not contact Google Fonts.

| Family | File | Style and weight range |
| --- | --- | --- |
| Newsreader | `newsreader-latin-variable.woff2` | Normal, 300–600, optical sizes 6–72 |
| Hanken Grotesk | `hanken-grotesk-latin-variable.woff2` | Normal, 400–700 |
| JetBrains Mono | `jetbrains-mono-latin-variable.woff2` | Normal, 400–500 |

Downloaded on 2026-09-06 from the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Newsreader:opsz,wght@6..72,300..600&family=Hanken+Grotesk:wght@400..700&family=JetBrains+Mono:wght@400..500&display=swap). Characters outside the bundled Latin subset use the CSS fallback stacks.
