# Ten-blend preview pack

Provided by the site owner as `tin-to-cellar-ten-blends.cellarpack.zip`.
The website copy preserves all original artwork bytes. Its manifest removes
unsupported `label`, `textColor`, and `preferredAlignment` properties from
each write-in overlay, leaving `{ "mode": "blank" }` as required by the schema.

`pack-aa` followed by `pack-ab` reconstructs the downloadable ZIP. The two
parts keep individual static assets below the hosting limit of 25 MiB.
Reconstructed SHA-256: `779f5777639711d06eefb98dea8c6655cdb929f50edee2e9639ca9f187be3a66`.

JPEG files are reduced previews only. Printing uses the full-resolution PNGs
inside the ZIP.
